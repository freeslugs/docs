## Overview

Fellow's P2P payment system revolutionizes how you send money to friends, family, and anyone else. Using just phone numbers, you can route money instantly between any financial platforms with true settlement in under 5 seconds.

<Note>
  **Universal Access**: Recipients don't need a Fellow account. They can claim payments instantly through any supported financial platform.
</Note>

## How P2P Routing Works

<Steps>
  <Step title="Enter Phone Number">
    Simply enter the recipient's phone number - no need for complex wallet addresses, account numbers, or usernames.
  </Step>
  
  <Step title="Select Source Platform">
    Choose where to send money from:
    - Your bank account
    - Apple Pay or Google Pay
    - Crypto wallet (Coinbase, Phantom, etc.)
    - Investment account
    - Any connected platform
  </Step>
  
  <Step title="Router Optimization">
    Fellow's router automatically determines the optimal path based on:
    - Recipient's preferred receiving method
    - Fastest settlement time
    - Lowest fees
    - Your routing preferences
  </Step>
  
  <Step title="Instant Settlement">
    Money routes through Fellow's infrastructure and settles on blockchain with true finality in under 5 seconds.
  </Step>
</Steps>

## P2P Payment Examples

### Scenario 1: Split Restaurant Bill

<CodeGroup>
```javascript Quick Split
// Split $120 restaurant bill among 4 friends
const splitPayment = await router.createSplit({
  amount: 12000, // $120.00 in cents
  recipients: [
    { phone: '+1234567890', share: 3000 }, // $30
    { phone: '+1234567891', share: 3000 }, // $30  
    { phone: '+1234567892', share: 3000 }, // $30
    { phone: '+1234567893', share: 3000 }  // $30
  ],
  from: 'apple_pay',
  memo: 'Dinner at Mario\'s - thanks everyone!'
});
```

```python Group Request
# Request money from multiple people
split_request = client.request_split(
    total_amount=12000,
    from_contacts=[
        {'phone': '+1234567890', 'amount': 3000},
        {'phone': '+1234567891', 'amount': 3000},
        {'phone': '+1234567892', 'amount': 3000},
        {'phone': '+1234567893', 'amount': 3000}
    ],
    to_account='checking_account',
    due_date='2024-01-15',
    memo='Mario\'s Restaurant - Split Bill'
)
```
</CodeGroup>

**What Happens:**
1. Each friend gets SMS with payment request
2. They can pay from any platform (Venmo, bank, crypto, etc.)
3. All payments route through Fellow and settle instantly
4. You receive consolidated payment in your chosen account

### Scenario 2: Cross-Platform Gift

```javascript
// Send birthday gift from crypto gains to traditional user
const gift = await router.send({
  from: 'coinbase_wallet',
  amount: 5000, // $50.00
  recipient: '+1234567890',
  asset: 'USDC',
  destinationHint: 'bank_account', // Suggest bank deposit
  memo: 'Happy Birthday! 🎉',
  priority: 'speed'
});

console.log(`Gift sent! Settlement: ${gift.estimatedSettlement}`);
// Output: Gift sent! Settlement: 4.2 seconds
```

**Routing Intelligence:**
- Detects recipient doesn't have crypto wallets
- Automatically converts USDC to USD
- Routes to recipient's preferred bank account
- Settles in under 5 seconds with SMS notification

### Scenario 3: International Remittance

```python
# Send money to family overseas
international_transfer = client.send(
    from_platform='bank_account',
    amount=50000,  # $500.00
    recipient='+52123456789',  # Mexico phone number
    destination_currency='MXN',
    routing_preference='cost_optimized',
    memo='Monthly family support'
)

print(f"Exchange rate: {international_transfer.exchange_rate}")
print(f"Recipient receives: {international_transfer.destination_amount} MXN")
print(f"Total cost: ${international_transfer.total_fee_usd}")
```

**Global Routing:**
- Fellow's router finds optimal USD → MXN path
- Uses stablecoin rails for instant cross-border settlement
- Recipient claims through local banking or crypto platforms
- 90% cheaper than traditional remittance services

## API Integration

### P2P Payment API

<CodeGroup>
```javascript Send Payment
import { FellowRouter } from '@fellow/router-sdk';

const router = new FellowRouter({
  apiKey: process.env.FELLOW_API_KEY
});

// Send P2P payment
const payment = await router.sendP2P({
  recipient: '+1234567890',
  amount: 2500, // $25.00 in cents
  from: 'apple_pay',
  memo: 'Coffee this morning!',
  priority: 'speed'
});

console.log('Payment ID:', payment.id);
console.log('Status:', payment.status);
console.log('Settlement ETA:', payment.settlementTime);
```

```python Request Payment  
from fellow import RouterClient

client = RouterClient(api_key=os.getenv('FELLOW_API_KEY'))

# Request payment from someone
request = client.request_payment(
    from_phone='+1234567890',
    amount=2500,
    to_account='checking_account',
    memo='Lunch money owed',
    due_date='2024-01-20'
)

print(f"Request ID: {request.id}")
print(f"Share link: {request.share_url}")
```

```bash Webhook Handler
# Handle P2P payment webhooks
curl -X POST https://api.fellow.app/v1/webhooks \
  -H "Authorization: Bearer $API_KEY" \
  -d '{
    "url": "https://yourapp.com/p2p-webhooks",
    "events": [
      "p2p.payment.sent",
      "p2p.payment.received", 
      "p2p.payment.claimed",
      "p2p.request.created"
    ]
  }'
```
</CodeGroup>

### Webhook Events

<AccordionGroup>
  <Accordion icon="paper-plane" title="Payment Events">
    **Outbound Payments:**
    - `p2p.payment.sent` - Payment initiated
    - `p2p.payment.routing` - Finding optimal path
    - `p2p.payment.settled` - Settlement confirmed
    - `p2p.payment.failed` - Payment failed
  </Accordion>
  
  <Accordion icon="inbox" title="Receiving Events">
    **Inbound Payments:**
    - `p2p.payment.received` - Payment received
    - `p2p.payment.claimed` - Recipient claimed payment
    - `p2p.payment.pending` - Waiting for recipient action
    - `p2p.payment.expired` - Unclaimed payment expired
  </Accordion>
  
  <Accordion icon="users" title="Group Events">
