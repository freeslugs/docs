## Overview

Fellow's cross-platform transfer system is the core of our global financial router. It enables you to move money instantly between any financial platforms - from Apple Pay to Coinbase, from traditional banks to crypto wallets, with true settlement in under 5 seconds.

<Note>
  **Industry First**: Fellow is the only infrastructure that enables true cross-platform routing between traditional finance and cryptocurrency with instant settlement and true finality.
</Note>

## How Cross-Platform Routing Works

<Steps>
  <Step title="Platform Analysis">
    Fellow's router analyzes your connected financial platforms and identifies all possible transfer paths between your source and destination accounts.
  </Step>
  
  <Step title="Path Optimization">
    The router evaluates each path considering:
    - Settlement speed and reliability
    - Total transfer costs and fees
    - Current liquidity and network conditions
    - Your personal routing preferences
  </Step>
  
  <Step title="Protocol Translation">
    Fellow handles the complex translation between different financial protocols:
    - Traditional banking (ACH, SWIFT, wire transfers)
    - Cryptocurrency networks (Ethereum, Solana, Bitcoin)
    - Payment platforms (Apple Pay, Google Pay, Venmo)
    - Investment platforms (Robinhood, Fidelity, E*TRADE)
  </Step>
  
  <Step title="Instant Execution">
    Your transfer executes through the optimal path with real-time monitoring and true blockchain settlement in under 5 seconds.
  </Step>
</Steps>

## Transfer Examples

### Example 1: Apple Pay to Coinbase

<CodeGroup>
```javascript Crypto Purchase
// Move money from Apple Pay to buy crypto on Coinbase
const transfer = await router.transfer({
  from: {
    platform: 'apple_pay',
    account: 'primary'
  },
  to: {
    platform: 'coinbase',
    account: 'usd_wallet'
  },
  amount: 50000, // $500.00 in cents
  priority: 'speed',
  purpose: 'crypto_purchase'
});

console.log(`Transfer ID: ${transfer.id}`);
console.log(`Settlement time: ${transfer.estimatedSettlement}`);
console.log(`Total fee: $${transfer.totalFee / 100}`);
```

```python Check Routing Path
# Analyze the routing path before executing
path_analysis = client.analyze_path(
    source='apple_pay',
    destination='coinbase',
    amount=50000,
    show_alternatives=True
)

for route in path_analysis.routes:
    print(f"Route: {route.path}")
    print(f"Settlement: {route.settlement_time}")
    print(f"Fee: ${route.fee / 100}")
    print(f"Success rate: {route.reliability}%")
    print("---")
```
</CodeGroup>

**What Happens:**
1. Fellow's router identifies you have $500 available in Apple Pay
2. Analyzes optimal path to Coinbase (likely via stablecoin rails)
3. Executes transfer with automatic USD→USDC→USD conversion
4. Funds arrive in Coinbase USD wallet in under 5 seconds
5. You can immediately purchase crypto with settled funds

### Example 2: Crypto Gains to Bank Account

```javascript
// Move crypto trading gains to traditional savings
const cryptoToBank = await router.transfer({
  from: {
    platform: 'phantom_wallet',
    asset: 'USDC',
    network: 'solana'
  },
  to: {
    platform: 'chase_bank',
    account: 'savings'
  },
  amount: 125000, // $1,250.00 in USDC
  priority: 'cost',
  conversion: {
    from_currency: 'USDC',
    to_currency: 'USD',
    slippage_tolerance: 0.1
  }
});

console.log(`Converting ${cryptoToBank.fromAmount} USDC to USD`);
console.log(`Bank deposit: $${cryptoToBank.toAmount / 100}`);
console.log(`Exchange rate: ${cryptoToBank.exchangeRate}`);
```

**Routing Intelligence:**
- Detects USDC balance in Phantom wallet
- Finds optimal USDC→USD conversion path
- Routes through stablecoin-to-bank bridge
- Settles in Chase savings account with real finality
- Total time: under 5 seconds vs 3-5 days traditional

## API Integration

### Cross-Platform Transfer API

<CodeGroup>
```javascript Transfer API
import { FellowRouter } from '@fellow/router-sdk';

const router = new FellowRouter({
  apiKey: process.env.FELLOW_API_KEY
});

// Execute cross-platform transfer
const transfer = await router.transfer({
  from: {
    platform: 'coinbase',
    asset: 'BTC',
    amount: 100000000 // 1 BTC in satoshis
  },
  to: {
    platform: 'fidelity',
    account: 'brokerage',
    currency: 'USD'
  },
  routing: {
    priority: 'balanced',
    max_slippage: 0.5,
    timeout: 300 // 5 minutes
  }
});

console.log('Transfer initiated:', transfer.id);
console.log('Estimated settlement:', transfer.eta);
```

```python Route Analysis
from fellow import RouterClient

client = RouterClient(api_key=os.getenv('FELLOW_API_KEY'))

# Analyze all possible routes
routes = client.analyze_routes(
    source_platform='apple_pay',
    destination_platform='phantom_wallet',
    amount=25000,  # $250.00
    destination_asset='USDC'
)

# Compare routing options
for route in routes:
    print(f"Path: {' → '.join(route.path)}")
    print(f"Settlement: {route.settlement_time}")
    print(f"Total cost: {route.total_fee_percentage}%")
    print(f"Success rate: {route.reliability}%")
    print("---")

# Execute optimal route
best_route = routes[0]
transfer = client.execute_transfer(route_id=best_route.id)
```
