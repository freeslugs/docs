## The Router Architecture

<Note>
  **Core Innovation**: Fellow's router acts as intelligent middleware that identifies optimal paths between any two financial platforms, handles protocol translation, and manages liquidity pools for instant settlement.
</Note>

### How the Router Works

<Steps>
  <Step title="Path Discovery">
    When you initiate a transfer, Fellow's router analyzes all possible paths between your source and destination platforms, considering factors like:
    - Settlement speed
    - Transaction costs
    - Liquidity availability
    - Network congestion
  </Step>
  
  <Step title="Intelligent Optimization">
    The router selects the optimal path based on your preferences:
    - **Speed Priority**: Routes that settle in under 5 seconds
    - **Cost Priority**: Most economical path (still under 30 seconds)
    - **Balanced**: Best overall value considering both speed and cost
  </Step>
  
  <Step title="Protocol Translation">
    The router handles the complex translation between different financial protocols:
    - Traditional banking (ACH, wire transfers)
    - Cryptocurrency networks (Ethereum, Solana, Bitcoin)
    - Payment platforms (Apple Pay, Venmo, PayPal)
    - Investment platforms (Robinhood, Coinbase, Fidelity)
  </Step>
  
  <Step title="Instant Settlement">
    Unlike competitors who provide "instant" UX but delayed settlement, Fellow achieves true instant settlement on blockchain with finality in under 5 seconds.
  </Step>
</Steps>

### API-First Architecture

<CodeGroup>
```javascript Router SDK
import { FellowRouter } from '@fellow/router-sdk';

const router = new FellowRouter({
  apiKey: process.env.FELLOW_API_KEY
});

// Route money between any platforms
const transfer = await router.route({
  from: 'apple_pay',
  to: 'phantom_wallet',
  amount: 100,
  recipient: '+1234567890'
});
```

```python Routing API
from fellow import RouterClient

client = RouterClient(api_key=os.getenv('FELLOW_API_KEY'))

# Get optimal routing path
path = client.get_optimal_path(
    source='coinbase',
    destination='bank_account',
    amount=500,
    priority='speed'
)

print(f"Settlement time: {path.estimated_time}")
print(f"Total cost: {path.total_fee}")
```
