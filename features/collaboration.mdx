## Overview

Fellow's high-yield account system automatically optimizes your earnings by intelligently routing your funds between traditional high-yield savings accounts, DeFi protocols, and yield-generating opportunities across all your connected platforms.

<Note>
  **Smart Yield Routing**: Fellow's router continuously monitors yield opportunities across traditional finance and DeFi, automatically moving your funds to maximize returns while maintaining your preferred risk level.
</Note>

## How Yield Optimization Works

<Steps>
  <Step title="Yield Discovery">
    Fellow's router continuously scans yield opportunities across:
    - Traditional banks and credit unions (FDIC insured)
    - Money market accounts and CDs
    - DeFi lending protocols (Aave, Compound)
    - Stablecoin staking and yield farming
    - Crypto staking rewards
  </Step>
  
  <Step title="Risk Assessment">
    Each opportunity is evaluated for:
    - Expected annual percentage yield (APY)
    - Risk level and insurance coverage
    - Liquidity constraints and lock-up periods
    - Historical performance and stability
    - Regulatory compliance status
  </Step>
  
  <Step title="Intelligent Allocation">
    Based on your preferences, Fellow automatically:
    - Allocates funds across optimal yield sources
    - Maintains your desired risk/reward balance
    - Preserves emergency fund accessibility
    - Compounds returns across platforms
  </Step>
  
  <Step title="Continuous Rebalancing">
    Fellow monitors and rebalances your allocations:
    - Moves funds to higher-yielding opportunities
    - Exits positions when yields decline
    - Maintains optimal portfolio allocation
    - Handles all protocol interactions automatically
  </Step>
</Steps>

```javascript Yield Optimization
// Configure automatic yield optimization
const yieldAccount = await router.createYieldAccount({

    includeCrypto: true,
```

```python Portfolio Monitoring
from fellow import YieldOptimizer

optimizer = YieldOptimizer(api_key=os.getenv('FELLOW_API_KEY'))

# Monitor current yield performance
performance = optimizer.get_performance(
    account_id='yield_account_123',
    period='30d'
)

print(f"Current APY: {performance.current_apy}%")
print(f"Total earnings: ${performance.total_earnings / 100}")
print(f"Best performing position: {performance.top_performer}")

# Analyze optimization opportunities  
opportunities = optimizer.analyze_opportunities(
    account_id='yield_account_123',
    min_improvement=0.25  # Minimum 0.25% APY improvement
)

for opp in opportunities:
    print(f"Move ${opp.amount/100} from {opp.current_position}")
    print(f"  to {opp.recommended_position}")
    print(f"  APY improvement: +{opp.apy_gain}%")
    print(f"  Additional annual income: ${opp.annual_gain}")
```

```javascript Yield Account Creation
import { FellowYield } from '@fellow/yield-sdk';

const yieldManager = new FellowYield({

const yieldAccount = await yieldManager.createAccount({
  name: 'Primary Yield Account',

    targetAPY: 6.5,
    riskTolerance: 'medium',
    liquidityRequirement: '24h',
    includeCrypto: true,
    includeDeFi: true,
    requireInsurance: false
  },
  limits: {
    maxSingleProtocol: 0.25, // 25% max
    maxCrypto: 0.50, // 50% max in crypto

  }
});

console.log(`Created yield account: ${yieldAccount.id}`);
console.log(`Target APY: ${yieldAccount.targetAPY}%`);
```

```python Automatic Rebalancing
from fellow import YieldManager

manager = YieldManager(api_key=os.getenv('FELLOW_API_KEY'))

# Configure automatic rebalancing
rebalancing = manager.configure_rebalancing(
    account_id='yield_account_123',
    settings={
        'frequency': 'weekly',
        'trigger_threshold': 0.5,  # 0.5% APY improvement
        'max_moves_per_month': 4,
        'gas_optimization': True,
        'tax_optimization': True,
        'min_position_size': 100000  # $1,000 minimum
    }
)

# Enable automatic execution
manager.enable_auto_rebalancing(
    account_id='yield_account_123',
    max_amount_per_move=500000  # $5,000 max per move
)

print("Automatic rebalancing enabled")
print(f"Next rebalancing check: {rebalancing.next_check}")
```
