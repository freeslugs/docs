## Security-First Architecture

Fellow is built with security as the foundation. As a global financial router handling billions in transactions, we employ multiple layers of protection to safeguard your funds and personal information.

<Note>
  **Trust & Transparency**: Fellow's security model is designed around zero-trust principles, end-to-end encryption, and regulatory compliance across all supported jurisdictions.
</Note>

## User Security Best Practices

### Account Security

<Warning>
  **Your Role**: While Fellow provides enterprise-grade security, your account security also depends on following best practices for password management and device security.
</Warning>

<AccordionGroup>
  <Accordion icon="key" title="Strong Authentication">
    **Password Security:**
    - Use unique, complex passwords
    - Enable two-factor authentication
    - Consider hardware security keys
    - Regular password updates
    
    **Device Security:**
    - Keep devices updated with latest security patches
    - Use device lock screens and encryption
    - Avoid public Wi-Fi for sensitive operations
    - Install apps only from official stores
  </Accordion>
  
  <Accordion icon="eye" title="Monitoring Your Account">
    **Regular Reviews:**
    - Monitor account activity regularly
    - Review transaction history monthly
    - Set up account alerts and notifications
    - Report suspicious activity immediately
    
    **Access Management:**
    - Log out of shared or public devices
    - Review and revoke unnecessary app permissions
    - Keep contact information updated
    - Use official Fellow apps and website only
  </Accordion>
</AccordionGroup>
