## Overview

Getting started with Fellow is simple - if you have a phone number, you already have access to Fellow's routing network. No complex verification or lengthy setup process required.

<Note>
  **Universal Access**: Fellow uses your phone number as your universal financial identifier, eliminating the need for complex wallet addresses or account numbers.
</Note>

## For Developers

### API Setup

<Steps>
  <Step title="Get API Credentials">
    Sign up for a developer account at [developer.fellow.app](https://developer.fellow.app)
    
    ```bash
    # Your credentials will include:
    API_KEY=flw_test_your_api_key_here
    API_SECRET=your_secret_key_here
    WEBHOOK_SECRET=your_webhook_secret_here
    ```
  </Step>
  
  <Step title="Install SDK">
    Choose your preferred SDK:
    
    <Tabs>
      <Tab title="Node.js">
        ```bash
        npm install @fellow/router-sdk
        ```
        
        ```javascript
        import { FellowRouter } from '@fellow/router-sdk';
        
        const router = new FellowRouter({
          apiKey: process.env.FELLOW_API_KEY,
          environment: 'sandbox' // or 'production'
        });
        ```
      </Tab>
      
      <Tab title="Python">
        ```bash
        pip install fellow-router
        ```
        
        ```python
        from fellow import RouterClient
        
        client = RouterClient(
            api_key=os.getenv('FELLOW_API_KEY'),
            environment='sandbox'
        )
        ```
      </Tab>
      
      <Tab title="REST API">
        ```bash
        curl -X POST https://api.fellow.app/v1/route \
          -H "Authorization: Bearer YOUR_API_KEY" \
          -H "Content-Type: application/json"
        ```
      </Tab>
    </Tabs>
  </Step>
  
  <Step title="Test Integration">
    Make your first routing API call:
    
    ```javascript
    const transfer = await router.createTransfer({
      from: 'apple_pay',
      to: 'coinbase',
      amount: 100, // $1.00 in cents
      recipient: '+1234567890',
      currency: 'USD'
    });
    
    console.log('Transfer initiated:', transfer.id);
    console.log('Estimated settlement:', transfer.estimatedSettlement);
    ```
  </Step>
</Steps>

### Webhook Setup

Configure webhooks to receive real-time routing notifications:

```javascript
app.post('/webhooks/fellow', (req, res) => {
  const signature = req.headers['fellow-signature'];
  const payload = JSON.stringify(req.body);
  
  // Verify webhook signature
  const expectedSignature = crypto
    .createHmac('sha256', process.env.FELLOW_WEBHOOK_SECRET)
    .update(payload)
    .digest('hex');
  
  if (signature === expectedSignature) {
    const event = req.body;
    
    switch (event.type) {
      case 'transfer.completed':
        console.log('Transfer completed:', event.data.transferId);
        break;
      case 'transfer.failed':
        console.log('Transfer failed:', event.data.error);
        break;
    }
  }
  
  res.status(200).send('OK');
});
```

## System Requirements

### Mobile Apps
- **iOS**: iOS 14.0 or later
- **Android**: Android 8.0 (API level 26) or later
- **Internet**: Stable internet connection required
- **Permissions**: Camera (for QR codes), Contacts (optional)

### API Integration
- **Webhook endpoint**: HTTPS required for production
- **Rate limits**: 1000 requests/minute (can be increased)
- **Supported formats**: JSON only
- **Authentication**: Bearer token authentication

## Security Setup

<Warning>
  **Important**: Enable two-factor authentication (2FA) on your Fellow account for enhanced security.
</Warning>

### Account Security

1. **Enable 2FA** - Use your phone's authenticator app
2. **Set spending limits** - Configure daily/monthly transfer limits  
3. **Review permissions** - Regularly audit connected platform access
4. **Monitor activity** - Enable real-time notifications for all transfers

### API Security

1. **Store credentials securely** - Never commit API keys to version control
2. **Use environment variables** - Load sensitive data from env files
3. **Rotate keys regularly** - Update API keys every 90 days
4. **Verify webhooks** - Always validate webhook signatures

## Troubleshooting

<AccordionGroup>
  <Accordion icon="phone" title="Phone verification issues">
    - Check that you entered the correct phone number
    - Ensure you have cellular or SMS service
    - Wait 2-3 minutes before requesting a new code
    - Contact support if codes aren't arriving
  </Accordion>
  
  <Accordion icon="link" title="Platform connection failures">
    - Verify your login credentials are correct
    - Check if the platform is experiencing outages
    - Try connecting from the platform's native app first
    - Some platforms require additional permissions
  </Accordion>
  
  <Accordion icon="code" title="API integration issues">
    - Verify your API keys are correct and active
    - Check that your webhook endpoint is accessible
    - Review rate limits and request formatting
    - Use sandbox environment for testing
  </Accordion>
</AccordionGroup>
