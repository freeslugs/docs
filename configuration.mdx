## Overview

Once you've connected your financial platforms to Fellow's router, you can customize how transfers are routed, set security preferences, and optimize your experience.

<Note>
  **Smart Defaults**: Fellow's router comes pre-configured with optimal settings, but you can customize everything to match your preferences.
</Note>

## Router Settings

### Default Routing Preferences

Configure how Fellow's router selects paths for your transfers:

<AccordionGroup>
  <Accordion icon="zap" title="Speed Priority">
    **Optimize for fastest settlement time**
    
    - Prioritizes routes that settle in under 5 seconds
    - May incur slightly higher fees for instant settlement
    - Best for urgent transfers and daily spending
    
    ```json
    {
      "routing_priority": "speed",
      "max_settlement_time": "5s",
      "allow_higher_fees": true
    }
    ```
  </Accordion>
  
  <Accordion icon="dollar-sign" title="Cost Priority">
    **Optimize for lowest fees**
    
    - Selects the most cost-effective routing path
    - May take slightly longer (still under 30 seconds)
    - Best for large transfers and cost-conscious users
    
    ```json
    {
      "routing_priority": "cost",
      "max_fee_percentage": 0.5,
      "allow_slower_settlement": true
    }
    ```
  </Accordion>
  
  <Accordion icon="balance-scale" title="Balanced">
    **Balance speed and cost (default)**
    
    - Optimizes for best overall value
    - Considers both settlement time and fees
    - Recommended for most users
    
    ```json
    {
      "routing_priority": "balanced",
      "max_settlement_time": "10s",
      "max_fee_percentage": 1.0
    }
    ```
  </Accordion>
</AccordionGroup>

## API Configuration

### Development Settings

For developers integrating Fellow's routing APIs:

<CodeGroup>
```javascript Environment Setup
// Environment configuration
const config = {
  environment: process.env.NODE_ENV === 'production' ? 'production' : 'sandbox',
  apiKey: process.env.FELLOW_API_KEY,
  webhookSecret: process.env.FELLOW_WEBHOOK_SECRET,
  baseUrl: process.env.NODE_ENV === 'production' 
    ? 'https://api.fellow.app' 
    : 'https://sandbox-api.fellow.app'
};

const router = new FellowRouter(config);
```

```python Rate Limiting
# Configure rate limiting
client = RouterClient(
    api_key=os.getenv('FELLOW_API_KEY'),
    rate_limit={
        'requests_per_minute': 100,
        'burst_capacity': 20,
        'retry_after': True
    }
)
```

```bash Webhook Configuration
# Configure webhook endpoint
curl -X POST https://api.fellow.app/v1/webhooks \
  -H "Authorization: Bearer $FELLOW_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://yourapp.com/webhooks/fellow",
    "events": ["transfer.completed", "transfer.failed"],
    "secret": "your-webhook-secret"
  }'
```
</CodeGroup>

### Custom Routing Rules

Create custom rules for specific routing scenarios:

<CodeGroup>
```javascript Amount-Based Routing
// Route large amounts through traditional banking
router.addRule({
  condition: { amount: { $gt: 10000 } },
  action: { 
    preferredPath: ['bank_account', 'ach'],
    requireApproval: true 
  }
});
```

```javascript Time-Based Routing
// Use different routing during business hours
router.addRule({
  condition: { 
    time: { between: ['09:00', '17:00'] },
    timezone: 'America/New_York'
  },
  action: { 
    preferredPath: ['instant_settlement'],
    maxFee: 0.02 
  }
});
```

```javascript Recipient-Based Routing
// Special routing for business partners
router.addRule({
  condition: { 
    recipient: { in: ['business_partners'] }
  },
  action: { 
    preferredPath: ['stablecoin', 'enterprise_rails'],
    notifications: ['email', 'slack']
  }
});
```
</CodeGroup>

## Configuration API

Manage settings programmatically:

<CodeGroup>
```javascript Get Current Config
const config = await router.getConfiguration();
console.log('Current routing preferences:', config.routing);
console.log('Security settings:', config.security);
```

```javascript Update Settings
await router.updateConfiguration({
  routing: {
    priority: 'speed',
    maxFee: 0.015
  },
  security: {
    dailyLimit: 7500,
    requireBiometric: true
  }
});
```

```javascript Bulk Configuration
// Apply configuration template
await router.applyTemplate('high_volume_business', {
  customizations: {
    dailyLimit: 100000,
    approvalWorkflow: true,
    complianceReporting: true
  }
});
```
</CodeGroup>
