## Getting Started with Fellow

Fellow is a consumer app that functions as a global financial router, enabling you to move money instantly between any financial platforms using just phone numbers. Here's how to get started:

<Note>
  **Universal Access**: If you have a phone number, you already have a Fellow account. Download the consumer app to start routing money between your accounts.
</Note>

## For Individuals

<Steps>
  <Step title="Sign Up">
    Use your phone number to access Fellow's routing network instantly. No lengthy verification process.
    
    <Card title="Download Fellow" icon="download" href="https://app.fellow.app">
      Get the Fellow app for iOS or Android
    </Card>
  </Step>
  
  <Step title="Connect Your Platforms">
    Link your existing financial accounts to the router:
    
    <CardGroup cols={2}>
      <Card title="Traditional Banking" icon="bank">
        Connect your bank accounts, Apple Pay, Google Pay
      </Card>
      <Card title="Crypto Wallets" icon="wallet">
        Link Coinbase, Phantom, MetaMask, and other wallets
      </Card>
    </CardGroup>
  </Step>
  
  <Step title="Start Routing Money">
    Transfer funds instantly between any connected platforms:
    
    ```bash
    Apple Pay → Phantom Wallet: <5 seconds
    Coinbase → Bank Account: <5 seconds  
    Venmo → Crypto Wallet: <5 seconds
    ```
    
    <Tip>All transfers settle on blockchain with true finality, not just balance updates.</Tip>
  </Step>
</Steps>

## For Developers

<Steps>
  <Step title="API Access">
    Get started with Fellow's routing APIs:
    
    ```bash
    curl -X POST https://api.fellow.app/v1/route \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "from": "apple_pay",
        "to": "coinbase_wallet", 
        "amount": 100,
        "recipient": "+1234567890"
      }'
    ```
  </Step>
