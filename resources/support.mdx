### Transfer & Routing Issues

<AccordionGroup>
  <Accordion icon="arrows-left-right" title="Failed Transfers">
    **Common Causes:**
    - Insufficient funds in source account
    - Platform maintenance or outages
    - Routing path temporarily unavailable
    - Account limits exceeded
    
    **Resolution Steps:**
    1. Check account balances and limits
    2. Verify platform status on our status page
    3. Try alternative routing path
    4. Contact support with transfer ID
  </Accordion>
  
  <Accordion icon="clock" title="Delayed Settlements">
    **Understanding Delays:**
    - Network congestion on blockchain
    - Banking hours and weekends
    - Additional compliance checks
    - Platform-specific processing times
    
    **What To Do:**
    - Check estimated settlement time
    - Monitor transaction status in app
    - Contact support if exceeds estimate
    - Request expedited processing if urgent
  </Accordion>
</AccordionGroup>

```python Error Reporting
import fellow

# Enable debug logging for support requests
fellow.set_debug_level('DEBUG')

try:
    transfer = client.create_transfer(
        from_platform='apple_pay',
        to_platform='coinbase',
        amount=10000  # $100
    )
except fellow.APIError as e:
    # Include full error details in support request
    support_data = {
        'error_type': type(e).__name__,
        'error_message': str(e),
        'request_id': e.request_id,
        'status_code': e.status_code,
        'response_body': e.response_body
    }
    print(f"Support data: {support_data}")
```

## Emergency Procedures

### Account Compromise

<Warning>
  **Immediate Action Required**: If you suspect your account has been compromised, take these steps immediately to protect your funds.
</Warning>

<Steps>
  <Step title="Secure Your Account">
    **Immediate Actions:**
    1. Change your password immediately
    2. Enable 2FA if not already active
    3. Log out of all devices
    4. Check recent transaction history
  </Step>
  
  <Step title="Contact Emergency Support">
    **Get Help Fast:**
    - Call: 1-800-FLW-HELP (24/7)
    - Email: security@fellow.app
    - Live chat: Mark as "Security Emergency"
    - Include: Account ID, suspected compromise time
  </Step>
  
  <Step title="Document the Incident">
    **Provide Details:**
    - Timeline of suspicious activity
    - Any suspicious emails or texts received
    - Devices used to access account
    - Any unauthorized transactions
  </Step>
  
  <Step title="Follow Up">
    **Complete the Process:**
    - Work with security team on investigation
    - Update all connected platform passwords
    - Monitor accounts for 30 days
    - Implement additional security measures
  </Step>
</Steps>
